Pronto em um minuto.

A extensão ainda não está na Chrome Web Store: instale direto do arquivo.

Baixe e descompacte

Baixe o zip e descompacte: fica uma pasta quanto-falta-extension.

Carregue no navegador

Abra chrome://extensions, ligue o Modo do desenvolvedor e clique em Carregar sem compactação.

Abra o Canvas

Abra o Canvas ↗: a semana e os avisos aparecem no painel, e a calculadora fica em Campus+ no menu lateral.

Você tinha notas salvas neste site.

A calculadora agora fica dentro do Canvas. Baixe o backup e, no Campus+, use Backup das notas → Importar arquivo.

Não pode instalar extensão? Use o favorito.

Arraste o botão para a barra de favoritos (Cmd+Shift+B no Mac, Ctrl+Shift+B no Windows mostra a barra). Com o painel do Canvas ou uma matéria aberta, clique nele: a semana, os avisos e quanto falta aparecem na página. Sem lembretes, tema e downloads, que precisam da extensão. Feito para Chrome, Brave e Edge.

Perguntas

Preciso de senha ou token do Canvas?

Não. A extensão usa o login que você já tem aberto no Canvas e só lê. Quem preferir pode usar um script com o próprio token, que roda no seu computador.

Minhas notas vão para algum servidor?

Não. A extensão e o favorito só falam com o próprio Canvas da PUCPR, e tudo fica guardado no seu navegador.

Não posso instalar extensão. Tem outro jeito?

Tem: o favorito. Arraste o botão para a barra de favoritos e clique nele com o Canvas aberto (Chrome, Brave ou Edge).

Funciona no celular?

Ainda não. A extensão é para Chrome, Brave ou Edge no computador, e o favorito para navegadores de computador.

É um sistema oficial da PUCPR?

Não. É um projeto de aluno, com os pesos dos Planos de Ensino de 2026/2. Confira sempre no Canvas.

E se um peso ou uma data estiver errado?

Mande pelo botão de feedback na calculadora ou abra uma issue no GitHub: dá para corrigir em minutos.

Quanto falta pra você?

Instale a extensão e abra o Canvas: o resto aparece lá.
