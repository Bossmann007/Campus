# Segurança

O Campus+ (antes Quanto falta) lida com as notas dos alunos e com a sessão deles no Canvas. Se você achou uma falha, **não abra uma issue pública**.

Reporte em particular pela aba **Security → Report a vulnerability** deste repositório. Respondo assim que puder.

O que conta como falha, por exemplo:

- a extensão ou o favorito enviando dados para fora do Canvas ou do site;
- a extensão abrindo um link, salvando um arquivo ou baixando algo de fora do Canvas da PUCPR;
- uma forma de rodar código na página a partir de um texto colado ou de um link;
- uma conta errada que faça alguém achar que passou quando não passou.

O que o projeto promete: nenhum servidor recebe notas, nenhum token do Canvas é pedido, a extensão só roda no Canvas da PUCPR, só faz leituras (nunca grava no Canvas) e guarda tudo no próprio computador.
