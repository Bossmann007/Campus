Caderno+

Conectar sua IA ao Canvas

Beta · Caderno+ MCP, um programa separado da extensão · não oficial

Com o Caderno+ MCP, a sua IA (Claude, ChatGPT desktop, Gemini, Cursor e outras) consegue responder "quanto falta em cada matéria?", "o que vence esta semana?" e "quais avisos novos?" com os seus dados do Canvas da PUCPR. Ele roda no seu computador e, no jeito recomendado, não usa token nenhum: lê um arquivo que a extensão Caderno+ grava com o que o painel mostra. Só lê: não entrega trabalho, não responde quiz, não manda mensagem, não marca nada.

Antes de conectar, saiba:

  • O que a IA consulta (notas, prazos, títulos de avisos e módulos, nomes das matérias) vai para o app de IA e, por ele, para a nuvem da empresa da IA (por exemplo, a Anthropic no Claude). Fica no histórico da conversa.
  • A IA consulta sozinha durante a conversa, sem pedir a cada vez (as consultas só leem). Também entram os títulos das avaliações e os links do Canvas.
  • Títulos escritos no Canvas podem ter nomes de professores ou colegas.
  • O cofre protege o token de arquivos e de outras contas do computador, mas não de programas que rodam com o seu próprio usuário.
  • Só se você escolher o jeito com token: o token do Canvas dá acesso total à sua conta. Quem limita a leitura é o Caderno+ MCP, não o token. Crie com validade até o fim do semestre e revogue quando parar de usar.
  • A política de API da Instructure (dona do Canvas), item 3(i), proíbe acessar o Canvas por servidores MCP que ela não aprovou. Sem token, o Caderno+ MCP não fala com o Canvas (só a extensão lê, como já faz); com token, ele fala. Não é aprovado pela Instructure nem pela PUCPR. Use por sua conta.

1. Ligue o arquivo na extensão (sem token)

  1. No botão da extensão Caderno+, ligue Arquivo para a sua IA.
  2. No Chrome, deixe desligado "Perguntar onde salvar cada arquivo" (Configurações → Downloads). Se estiver ligado, a extensão desliga o arquivo e avisa.
  3. Abra o Canvas uma vez. A extensão grava caderno-agente.json na pasta PUCPR dos seus Downloads e atualiza a cada leitura.

Sem token, os dados são os da última vez que você abriu o Canvas, e o "quanto falta" inclui as notas que você digitou. Os módulos das matérias só vêm com token.

Opcional: com token (dado na hora e módulos)
  1. No Canvas da PUCPR: Conta → Configurações.
  2. Na página de configurações, clique em + Novo token de acesso.
  3. Finalidade: Caderno+ MCP. Expira: o último dia do semestre.
  4. Copie o token. Ele aparece uma vez só; não mande para ninguém. O Caderno+ MCP guarda ele no cofre do seu sistema (Keychain no Mac, cofre do usuário no Windows, Secret Service no Linux).

2. Escolha o seu app

Claude Desktop (Mac e Windows) em breve

O mais fácil, sem instalar nada além do Claude: baixe o arquivo caderno-mcp.mcpb e abra com dois cliques. Deixe o campo do token vazio para usar o arquivo da extensão (ou cole um token, se escolheu esse jeito). O Claude já traz o que precisa para rodar.

Outros apps em breve

Precisam do Node.js 18 ou mais novo instalado. Vão funcionar: Claude Code, ChatGPT desktop e Codex (CLI e IDE), Gemini CLI, Cursor, VS Code, Windsurf, Zed, JetBrains, LM Studio, Goose, Cline, Roo, Continue e Perplexity (Mac).

Ainda não publicado. Os comandos de cada app aparecem aqui quando o Caderno+ MCP for publicado. Até lá, não instale nenhum pacote chamado "caderno-mcp" de outro lugar: só a versão indicada nesta página é a nossa, e ela vai pedir o seu token.

Só pela web (ChatGPT web, Claude web, Gemini app, Le Chat, Grok)

Não funcionam: esses apps só falam com servidores na internet, e o Caderno+ MCP fica no seu computador de propósito, para o token não sair dele. No ChatGPT, use o app desktop.

3. Pergunte

"Quanto falta em cada matéria?", "o que vence esta semana?", "quais avisos novos?", "quais módulos tem em Banco de Dados?". Os números de "quanto falta" são os mesmos do painel do Caderno+, só com as notas do Canvas (as que você digita à mão na extensão não entram).

Parar

O comando logout do Caderno+ MCP apaga o token do cofre. Revogue o token também no Canvas (Conta → Configurações) e remova o servidor do app. No Claude Desktop, desinstale a extensão em Configurações → Extensões.

Veja também a política de privacidade. Código aberto: github.com/Bossmann007/Campus.
