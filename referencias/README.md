## O que entrou no notas-v4.html

O arquivo tem uma CSP que bloqueia rede, então nada de biblioteca externa nem fonte da web. Tudo foi feito em CSS puro:

- Tremor / shadcn (dashboards): cartões de KPI com número grande em `tabular-nums`, rótulo pequeno em caixa alta, bordas de 1px bem discretas.
- dark.design / Linear-style SaaS: fundo quase preto com um brilho radial suave no topo e uma grade de pontos sutil.
- Magic UI / Aceternity (borda e brilho): borda do cartão acende no hover com um gradiente que segue o mouse (`--mx`/`--my`).
- motion.dev / eased.dev / transitions.dev: entrada em cascata dos cartões e barra de progresso que cresce com `cubic-bezier(.22,1,.36,1)`; tudo desligado com `prefers-reduced-motion`.
- uiverse.io (inputs): campo de nota com anel de foco colorido e estado inválido vermelho.
- Typewolf / Fontpair: par serifado de exibição (New York / Iowan, fontes do macOS) para títulos + sans do sistema para o resto; números em monoespaçada.
- Barra de navegação fixa com os nomes das matérias (navbar.gallery) e status de cada matéria em pílula.
