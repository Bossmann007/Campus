Caderno+Sua IA

Sua IA, com o seu Canvas.

O Caderno+ MCP é um programinha que roda no seu computador e deixa o Claude, o ChatGPT desktop, o Gemini ou o Codex lerem o seu Canvas: quanto falta (com a fórmula do Centro de Notas), o que falta entregar, a semana, as notas, os quizzes, os avisos, os módulos e os professores. Sem token e sem servidor: ele pergunta para esta extensão, que lê o Canvas com o login do seu navegador.

  1. Instale o Caderno+ MCP no app da sua IAClaude Desktop: abra o arquivo .mcpb e, quando ele pedir, cole o id da extensão (as letras do comando do passo 2). Claude Code, Codex, Gemini CLI e outros: npm install -g caderno-mcp e depois caderno-mcp setup mostra a linha para o seu app. betaPasso a passo por app ↗
  2. Ligue a ponteRode este comando uma vez no terminal (ele registra a ponte no seu navegador) e clique em Ligar. O navegador pede para o Caderno+ "se comunicar com aplicativos nativos cooperativos": é a ponte. caderno-mcp ponte …
  3. PergunteUse as perguntas abaixo, ou as suas; a matéria pode ser só um pedaço do nome ("banco", "imperativa"). Deixe o navegador aberto: a IA consulta o Canvas na hora, só leitura.
O que a ponte faz. Só leituras do Canvas da PUCPR e do Centro de Notas, pedidas pelo Caderno+ MCP do seu computador. Nada é enviado para servidor nosso; o que a IA consulta vai para o app de IA. Enquanto ligada, o processo de fundo do Caderno+ fica acordado. Para desligar: o botão Desligar acima (tira também a permissão); para tirar a ponte do computador, caderno-mcp ponte remove.
Uso pessoal com token (sem a ponte)

Também dá para usar um token do Canvas (Conta → Configurações → "+ Novo token de acesso") guardado no cofre do sistema com caderno-mcp login. A documentação do Canvas não permite pedir isso a outros alunos: é só para você. Nunca cole o token em chat. Abrir configurações do Canvas ↗
